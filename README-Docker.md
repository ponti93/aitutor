# 🚀 AI Tutor Agent - Docker Deployment

This branch (`docker-deployment`) is optimized for deployment to **Render** using Docker.

## 📋 Deployment Configuration

### **Render Settings:**

#### **Build Command:**
```bash
pip install -r requirements.txt
```

#### **Start Command:**
```bash
python app.py
```

#### **Environment Variables:**
- `DATABASE_URL`: PostgreSQL database connection string
- `SECRET_KEY`: Flask secret key (auto-generated)
- `GEMINI_API_KEY`: Your Google Gemini API key
- `FLASK_ENV`: Set to `production`

## 🐳 Docker Configuration

### **Files Created:**
- ✅ `Dockerfile` - Python 3.11 slim image with all dependencies
- ✅ `.dockerignore` - Optimizes build process
- ✅ `render.yaml` - Render deployment configuration

### **Docker Features:**
- **Multi-stage build** for smaller image size
- **System dependencies** for image processing (Tesseract OCR)

## 🚀 Quick Deployment to Render:

### **Step 1: Connect Repository**
1. Go to [Render Dashboard](https://dashboard.render.com)
2. Click "New +" → "Blueprint"
3. Connect your GitHub repository: `https://github.com/ponti93/aitutor.git`
4. Select the `docker-deployment` branch

### **Step 2: Configure Service**
- **Name**: `ai-tutor-agent`
- **Environment**: `Python`
- **Build Command**: `pip install -r requirements.txt`
- **Start Command**: `python app.py`

### **Step 3: Add Environment Variables**
```bash
GEMINI_API_KEY=your_gemini_api_key_here
FLASK_ENV=production
```

### **Step 4: Deploy**
- Click "Create Web Service"
- Render will automatically build and deploy your app

## 🔧 Local Development with Docker

### **Build Image:**
```bash
docker build -t ai-tutor-agent .
```

### **Run Container:**
```bash
docker run -p 5000:10000 -e GEMINI_API_KEY=your_key ai-tutor-agent
```

### **Run with Docker Compose:**
```bash
docker-compose up
```

## 🛠️ Troubleshooting

### **Common Issues:**

**Build Fails:**
- Check that all dependencies are in `requirements.txt`
- Ensure system dependencies are installed in Dockerfile

**App Won't Start:**
- Verify environment variables are set correctly
- Check database connection string format

**Memory Issues:**
- Monitor memory usage in Render dashboard
- Consider upgrading to larger instance if needed
